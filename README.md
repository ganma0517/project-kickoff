# Project Kickoff

以一次一題的引導訪談，協助新手建立有秩序、可維護、可接續的專案。

## Skill

完整指引與資源位於 [skill/project-kickoff](skill/project-kickoff)。

下載本儲存庫 ZIP，解壓後將完整 `skill/project-kickoff/` 資料夾放到 `~/.claude/skills/project-kickoff/`，或專案 `.claude/skills/project-kickoff/`。若已有同名版本，先比較再更新。不要只複製 SKILL.md。

啟動 Claude Code，輸入 `/project-kickoff`，說明你要新建專案。助手一次問一題，提出資料夾、版本與 Context 方案，依已確認答案和授權建檔並核對。

## 教材

`index.html` 為十頁互動教材；`project-report-interactive.html` 為互動報告。下載後可在瀏覽器離線開啟。頁內終端機與用量數字為教學模擬，不會實際建檔或呼叫 AI。

## 範圍與驗證

保存不等於壓縮，Skill 不修改模型上限或系統門檻。新的逐題訪談規則尚待跨 AI 行為實測；不宣稱已量測 Token 節約或真人學習成效。
