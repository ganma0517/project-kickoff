# 終端機與 Claude Code 常用指令對照

使用者問「這個指令是什麼」時查這裡回答。說明用白話，一句話講用途，一句話講什麼時候用。

## 看位置與檔案

| 指令 | 用途 | 什麼時候用 |
|------|------|-----------|
| `pwd` | 顯示現在在哪個資料夾 | 不確定自己在哪時 |
| `ls` | 列出這個資料夾裡有什麼 | 想看檔案有沒有建好 |
| `ls -la` | 同上，連隱藏檔（.gitignore 這種）一起列 | 檢查設定檔在不在 |
| `cd 資料夾名` | 進入某個資料夾 | 要在專案裡工作前 |
| `cd ..` | 回上一層 | 走錯了 |
| `cat 檔名` | 把檔案內容印出來 | 看短檔案 |
| `head -20 檔名` | 只看前 20 行 | 檔案很長只想看開頭 |

## 版本管理（git）

| 指令 | 用途 | 什麼時候用 |
|------|------|-----------|
| `git init` | 開始追蹤這個資料夾 | 專案開工，`.gitignore` 寫好之後 |
| `git status` | 看哪些檔案改了、哪些還沒加進去 | 任何 git 動作之前先看一眼 |
| `git add 檔名` | 把檔案放進下一次存檔的清單 | 確定這個檔要記錄 |
| `git commit -m "說明"` | 存一個版本，附一句說明 | 一個小段落做完 |
| `git ls-files` | 列出版控實際追蹤的檔案 | 推上網之前確認沒混進不該有的 |
| `git log --oneline` | 看歷史版本一行一個 | 想回頭找某次改動 |
| `git checkout -b 分支名` | 開一條新分支 | 大改動前，不在 main 上直接動 |

## Claude Code 對話指令

| 指令 | 用途 | 什麼時候用 |
|------|------|-----------|
| `/context` | 看目前對話用了多少空間、什麼占最多 | 感覺對話很長了、或一個階段做完時 |
| `/compact` | 立刻壓縮對話歷史 | 用量高但還想繼續這個對話 |
| `/compact focus on X` | 壓縮時特別保留 X 相關內容 | 接下來還要用到 X 的細節 |
| `/clear` | 清空對話重新開始 | 一個階段完全做完，結論已寫檔 |
| `! 指令` | 在對話裡直接跑一個終端機指令 | 需要自己執行互動式登入之類的東西 |

## 新手最常卡的三件事

1. 路徑有空格要加引號：`cd "AI Agent"`，不加會被當成兩個參數。
2. `~`（家目錄）要放在引號外面：`cd ~/"Downloads/AI Agent"` 可以，`cd "~/Downloads/AI Agent"` 會找不到資料夾，因為引號裡的 `~` 不會展開。給使用者的指令一律照這個寫法。
3. 打錯指令按 `Ctrl+C` 取消，畫面亂掉按 `Ctrl+L` 重繪。
4. `git` 說 `nothing to commit` 不是錯誤，是沒有新改動。
